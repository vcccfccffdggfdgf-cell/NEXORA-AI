NEXORA AI — Official Minimal Edition

Upload ALL files in this folder to the root of your existing Netlify site.
Keep index.html, styles.css, app.js and icon.svg together.

Included:
- Responsive desktop and mobile layouts
- Fully translated English, Arabic (RTL), and French interface
- Saved conversations, history search, export, and delete
- New chat, assistant modes, prompt shortcuts
- File picker and browser speech input (when supported)
- Minimal black/white design with subtle transitions

Important limitations:
This is a front-end prototype. It does not connect to ChatGPT, Grok, Claude, Gemini, or a live web-search provider.
Messages are saved locally but generated AI answers require a secure backend and an AI provider connection.
File selection currently records the filename only; it does not upload or analyze the file.
